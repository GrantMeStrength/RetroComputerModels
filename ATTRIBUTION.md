[Pinshape item 103727](https://pinshape.com/items/103727-3d-printed-commodore-64-breadbin-enclosure),
**[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)**.
Retain this attribution and license link with redistributions of the
reference-derived model material. No endorsement is implied.

Changes: newly constructed extrusion/Boolean shell geometry informed by measured
reference dimensions and opening/profile locations; simplified separately authored
keyboard geometry and original raster artwork; 14 mm-tall key bodies. The VIC-20
is a color/artwork variant of the same C64 geometry, not an independently measured
VIC-20 enclosure. Reference mesh topology, internal posts, print splits and source
materials are not included. The separately licensed `Platte.stl` connector plate
was not used and is not included.
