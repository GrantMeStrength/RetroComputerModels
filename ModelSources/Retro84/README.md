# Retro84 — original fictional concept

**Retro84 is an original imagined 1984 keyboard computer, not a historical
machine or a replica of a real product.** Original geometry, a folded-wing mark,
print layouts and palette give it a low mineral-colored wedge, dark lower shell,
slate keycaps, four amber function keys and a petrol-green badge inlay.
No historical photographs or third-party mesh topology are used.

The design has 60 centered main keys plus four function keys, tapered/dished
caps, a crowned spacebar, separate keyboard plates/supports, a 1.6 mm PCB,
open vents, recessed screws, feet and rear cassette/video/controller/DC fittings.
The expansion cover is closed; there is no exposed cartridge connector or
physical cassette deck. No CPU, RAM capacity, electrical rating or proprietary
pinout is fixed into the artwork.

Overall envelope: **364 × 218.747 × 50.25 mm**, including feet and rear switch.
Main key pitch is 19 mm; the deck slopes 5.71°. The 225 closed meshes and
44,894 triangles form an illustrative assembly, not a wired circuit, tooling
CAD, certified connector system or manufacturing-ready enclosure.

## Editing and game use

Open `retro84.blend` for editable geometry, materials, four packed artwork
images and named `Assembly_*` parents, or `retro84.usdz` for viewing.
The transparent model-only preview is suitable for illustrations and share cards.

This supplies **one fixed wedge / “Keyboard Computer” representation**.
Different game case styles, keyboard mechanisms, storage devices, optional
ports and component choices are not automatically reflected in its geometry.
Named parts support manual adaptation, not a working modular game system.
Hiding a port does not close its enclosure aperture.

`Case_upper` and `Case_lower` control the main case plastics. Keep separate
rubber, key, metal and badge materials intact when recoloring. Some printed
backgrounds are baked into the atlases: a different case/key color may also
require editing and repacking the matching artwork, not only changing a
plastic material. No generator, earlier-name backup or raw design pipeline is
included.
